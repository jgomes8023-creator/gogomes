# SoundCanvas Full Package Release

This directory contains the packaged release of the SoundCanvas application. It includes all necessary files and scripts to install and run the app on supported platforms.

## Included in the Package:
- **Complete Project Codebase**: Backend, frontend, and required scripts.
- **Install Scripts**:
  - `install.sh`: For Linux/macOS systems.
  - Coming soon: Windows and mobile-specific installers.
- **README Documentation**: Comprehensive setup guides for each platform.

## How to Download and Use:
1. Navigate to the `Releases` section of the repository.
2. Download the `.zip` or `.tar.gz` file.
3. Extract the file and follow the respective platform's setup instructions provided in the README.
